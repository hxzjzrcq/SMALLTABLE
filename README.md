# SMALLTABLE

SmallTable 是供朋友们在线跑团使用的共享桌面。主持人放上地图和棋子，大家一起移动棋子、测量距离、掷骰和记先攻；规则本身交由人判断，软件负责保存和同步桌面。

每套部署提供一张桌面。玩家通过浏览器连接，填写临时昵称和房间密码即可进入，不需要注册个人账号。当前版本为 **0.7.3**。

本项目主要由 **GPT6.1SOL** 制作。

## 能做什么

- **地图与棋子：** 主持人上传和切换地图、创建和克隆棋子；所有人都能移动可见棋子，也能从公共棋子盒取用。
- **桌面工具：** 按格测距、共享画线、手动维护先攻表，或 `1d20+5 侦查陷阱` 这样的骰式。
- **笔记与属性：** 棋子可附公开注释，主持人另有私有说明。支持个人笔记，保存在自己的浏览器。内置 DNDROLL 可生成角色属性。
- **音乐与存档：** 主持人可播放 MP3，玩家自行选择是否收听；桌面自动保存，也可导出含地图与棋子图片的 ZIP 备份。

默认支持 15 名普通玩家和 1 名独立主持人（DM），可在配置中调整。详细操作见[设置与使用帮助](帮助.md)。

## 怎样开始

**如果朋友已经搭好了桌面：** 打开对方提供的网址，输入临时 ID 和房间密码。主持人使用 DM 密码登录。

**如果你要自己运行：** 安装 Node.js 22 或更新版本（含 npm），下载并解压源码，在含 `package.json` 的目录打开终端。

1. 运行 `npm ci` 安装依赖。
2. 将 `.env.example` 复制为 `.env`，把 `ROOM_PASSWORD` 和 `DM_PASSWORD` 改成两个不同的有效密码。[帮助](帮助.md#首次安装)。
3. 构建并启动：

   ```bash
   npm run build
   npm start
   ```

4. 本机浏览器打开 <http://127.0.0.1:3000/>。

首次设置完成后，Windows 用户可以双击根目录的 `START-SMALLTABLE.cmd` 启动。让其他电脑或远程朋友连接，还需设置监听地址、网络访问或代理，见[部署说明](帮助.md#局域网与公网部署)。

## 使用前需要知道

- 轻量级手动桌面工具，原则上不提供真实线下桌面无法直接实现的功能，比如自动战斗、自动规则裁决、战争迷雾。
- 所有人都能移动可见棋子，没有棋子所有权或拖动锁。
- 运行需要持续工作的 Node.js 服务和可保存数据的目录，不能只把前端文件上传到静态网站空间。

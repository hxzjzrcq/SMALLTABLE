# SMALLTABLE 0.7.3

本项目主要由 **GPT6.1SOL** 制作。

一套部署就是一张共享桌面。填写临时 ID，以房间密码或 DM 密码入桌。规则由人解释，软件保存并同步桌面。

0.7.3 修复连续放置完全重叠、玩家批量归还被过期 ID 阻断两项问题；见 [0.7.3 修订](docs/UPGRADE-0.7.3.md)。

0.7.2 增加公共 A–Z 棋子盒、普通棋子隐藏/显形、四字符棋面文字、列表定位、真实上传进度和最终移动回执。昵称上限为 16 单位，健康在线不因无操作退出，断线后固定 45 分钟可恢复。首次安装阅读 [设置与使用帮助](帮助.md)，升级前阅读 [0.7.2 升级](docs/UPGRADE-0.7.2.md)：当前 schema 为 4，拒绝旧存档且不迁移。

历史变更见 docs/UPGRADE-*.md，不作为当前合同补丁。

固定 Windows 启动入口为项目根目录 `START-SMALLTABLE.cmd`，仅包含通用提示；个人穿透地址、配置和凭证自行保存在本地。

## 本地运行

需要 Node.js 22 或更新版本及 npm。安装、生产启动和代理约定见 [依赖与部署](docs/DEPENDENCIES.md)。

```bash
npm ci
```

复制 `.env.example` 为 `.env`，首次启动前设置两个不同的初始密码，或先运行 `npm run password:reset` 初始化。密码要求和重置步骤见 [密码管理](docs/SECURITY.md#密码管理与重置)。

开发模式：

```bash
npm run dev
```

打开 `http://127.0.0.1:5173`。Vite 代理 API、素材与 WebSocket 到本机 3000 端口。

本地生产模式：

```bash
npm run build
npm start
```

打开 `http://127.0.0.1:3000`。一个 Node.js 进程提供前端、API 和 WebSocket。默认仅监听本机；当前交付不包含实际部署。

发布包包含前端构建产物 `dist/`，仍需安装依赖。构建后可只安装生产依赖启动，具体步骤和部署边界见 [依赖与部署](docs/DEPENDENCIES.md)。

## 使用

1. 填写临时 ID 和房间密码；也可直接输入 DM 密码以 DM 身份登录。普通玩家默认 15 席，DM 默认独立 1 席。健康在线不按用户活动过期；断线后有 45 分钟恢复资格，不保留在线席位。没有个人账号；同一浏览器配置文件共用一个会话。
2. 普通玩家可在 DM 工具面板输入 DM 密码升级，须有 DM 空位。DM 可查看在线列表并踢出普通玩家。可添加、切换、删除地图和独立缩放背景、调整格距、创建无图片棋子、维护骰子名称名单；“密码管理”可在再次验证当前 DM 密码后修改口令。
3. 公共盒 A–Z 共 26 枚，人人可取用、改字和归还；普通池默认额外 255 枚。普通与公共棋面文字均为 1–4 个 Unicode 码点。DM 可在列表隐藏/显形普通棋子、克隆公共棋子为普通副本。PC 双击条目或点击“定位”只改变本机视角。
4. DM 在棋子面板编辑名称、编号、颜色、占地边长与 DM 私有说明，可附图片；点“保存修改”提交。所有玩家都能单独编辑并保存公开注释。
5. DM 可在棋子目录逐枚点击“克隆”，复制当前棋子并共用图片；说明随后独立修改。选择工具下 Shift＋点击加选或取消选中，普通点击替换选择；DM 按 Delete 经一次确认删除普通棋子并归还公共棋子；PL 只能归还公共棋子，不支持集体移动、旋转或编辑。所有人可移动和旋转当前可见棋子；隐藏棋子不能移动或旋转。拖空白平移，滚轮、双指或按钮缩放，“查看全部”找回地图外棋子。
6. “丈量”拖出本机直线测距，整数格显示。格距按地图像素定义，隐藏网格也能测距。
7. 骰盘选择 DM 提供的显示名称。支持 `d20`、`4d6`、`1d20+5`、`2d6+1d4-2`；可附空格及最多 32 个 Unicode 字符的公共理由，例如 `1d20+5 侦查陷阱`。
8. 笔记仅保存在浏览器，可复制、导出、导入 TXT。跨设备自行转移。
9. 顶部“属性工具”打开内置 DNDROLL，所有人都可用；生成、分配、购点、存档与导出均复用提供的 DNDROLL 0.4 Core。工具数据只在本机，不自动广播或绑定棋子。
10. 手机可关闭和滚动侧栏；新功能提供可点击的定位、归还、隐藏/显形和批量删除入口。
11. DM 可导出、恢复含所有地图与棋子图片的房间 ZIP 备份。备份包含 DM 私有说明，不含私人笔记、密码、连接凭证或音乐。音乐独立保存，恢复房间时保留当前音乐及播放状态。

先攻盘支持名字、数字、增删修改和排序；直线画笔支持共享画线与删除，DM 可清空线条。DM“掀桌”经一次确认删除全部棋子和画线，保留地图、先攻、骰子及音乐，无撤销。

房间音乐位于桌面工具栏下方。DM 上传 MP3 后可播放、暂停、停止和删除；每次切曲，玩家独立接受或拒绝。拒绝者不请求音频，接受者可调本地音量和静音。浏览器阻止播放时点“点击播放”。完整交互见 [UI](docs/UI.md#房间音乐)。

图片棋子没有有色底板，透明区域保持透明，完整占地区域仍可选中、拖动；选中框与旋转保留。无图片棋子继续显示彩色圆形或方形。

登录前可查看本机私人笔记。登录动画在后台或减少动态效果模式下暂停，登录后卸载。手机使用单列登录表单。

“角色卡管理”仅为提示占位，没有存储或管理功能。没有撤销、拖动锁、聊天或棋子所有权。圆形棋子没有方向刻线。两个玩家争抢同一枚棋子时允许跳动，以服务器接受的最后更新为准。

# 当前安全与授权

适用于 SMALLTABLE 0.7.3。普通限额见 [配置](CONFIGURATION.md)，运行部署见 [依赖与部署](DEPENDENCIES.md)。

## 授权登记

`src/server/permissions.ts` 分别登记 HTTP 路由和 WebSocket 动作；未知动作默认拒绝，包括 DM。新增 schema 命令必须同时登记权限；已登记但没有实现的命令明确报错，不保存、不增加 revision、不广播。

| WebSocket 权限 | 明确列出的动作                                                                                                                                                                    |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 普通玩家及 DM  | activity、unlock、lock、move、rotate、note、roll、initiative.put、initiative.delete、initiative.order、drawing.add、drawing.delete、public.take、token.label、delete、delete.many |
| 仅 DM          | drawing.clear、create、edit、token.hidden、player.kick、clear、grid、names、map.select、map.delete、map.scale、music.play、music.pause、music.stop、music.delete                  |

| HTTP 权限                               | 路由                                                                                                                     |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 无会话可访问                            | GET /api/config、POST /api/login、POST /api/logout                                                                       |
| 有效会话                                | GET /media/:id、GET /audio/:id、GET /api/health、GET /api/session、POST /api/session                                     |
| 有效会话、DM 已解锁且保留原有 s.ws 条件 | POST /api/image/:kind、GET /api/backup、POST /api/restore、POST /api/passwords、POST /api/music、POST /api/upload/cancel |

health 的匿名请求返回 401。静态页面及内嵌工具资源仍可加载。管理路由在入队前和执行队列时均检查；密码修改再次验证当前 DM 密码。epoch、来源、人数、名单和限流仍由各自入口检查；不是权限登记的替代品。React 显隐不作为授权依据。

普通玩家的快照与棋子增量均经过 `project` / `publicToken`，不含 DM 私有说明。管理列表只发送给在线 DM，不含登录 Token。公共改字只允许公共对象或 DM；PL 批量删除跳过已不存在的 ID，处理剩余公共对象；混入仍存在的普通对象整体拒绝。隐藏不是保密，列表和公开坐标不隐藏；DM 私有说明持续过滤。角色撤销、断线或退出会清除客户端 DM 视图、私有草稿及管理列表。

## 会话与席位

- 登录校验必填临时 ID 和单个密码；房间密码产生普通角色，DM 密码直接产生 DM 角色。普通与直接 DM 登录共用登录限流（容量 20，每秒补充 0.1）；工具箱解锁与改密分别使用独立限流桶（各容量 5，每秒补充 0.05）。三者均按 TCP 对端 IP 计数，不信任转发头；代理或相同出口下仍可能共享各自的桶。输错入房密码不消耗管理限额。异步验密返回后再次检查密码代次、会话、容量和 ID。
- 浏览器认证只通过 HttpOnly、SameSite=Strict Cookie；登录/恢复响应不返回凭证，WebSocket 使用同源 Cookie。HTTPS 部署开启 COOKIE_SECURE。健康在线每 10 秒的服务端维护通知触发 Cookie 续期，Cookie 在线时保持 45 分钟有效期；离线查询只返回固定断线期限的剩余时间，不延长资格。应用不提供 TLS。
- 健康在线不因无操作过期，不依赖鼠标、键盘或 iframe 活动。断线从服务端确认断开起固定保留 45 分钟资格；恢复成功清除离线截止时间，失败重试不延期。每 10 秒检查心跳，连续漏回三次终止连接，pong 清零计数。维护定时器停顿一次只计一次。主动注销、被踢、撤权、替换等终止语义及重启失效不变。
- 断线保留有效会话，但释放在线席位和 ID。握手占位最长 15 秒，失败或超时释放；普通和 DM 分别计数，配置见 [配置](CONFIGURATION.md)。恢复重新检查容量与名称，不预留离线席位、不自动降级或抢占。满员保留认证，允许手动重试；ID 冲突要求更换 ID 重新登录。
- 临时 ID 仅允许 ASCII 字母数字及 Unicode Unified_Ideograph 汉字，按码点计算 1–16 单位，汉字占 2。英文字母忽略大小写判重，在线和有效握手占位共用名称范围。名称仅为显示，不写入房间、骰点、棋子或备份。
- 一个会话最多一条有效桌面连接。新连接接管原席位，即使房间已满也可接管；旧连接停止重连，迟到关闭、消息及排队命令不能影响新连接。target 是每次连接/角色对应的非秘密随机 UUID，断线、接管和角色改变即失效。
- DM 只能踢当前在线普通玩家，不能踢自己或其他 DM；执行时复查操作者角色及目标 target。先撤销会话再断开，被踢者可重新认证，不封禁。有效但离线的 DM 不得执行管理或写 API。
- 主动锁定尝试转入普通席位，无名额则注销并退出。收起 UI 不撤权。会话保留最初的 room/dm 认证来源，升级或降级不改写来源。
- 主动离开调用来源校验的幂等注销接口，撤销会话并清除 Cookie。刷新、卸载不注销。断网退出只保存无凭证的待注销标记；恢复联网或重新初始化时先注销，不恢复桌面。认证与注销在客户端有顺序保护，避免在途登录迟到重新留下 Cookie。
- 同一浏览器配置文件同一站点共用 Cookie；多标签页会接管同一身份。多人测试需独立配置文件或隔离上下文。密码、Token 不进入 localStorage/sessionStorage、URL 或日志；私人笔记不随活动上传。

### 密码变更的会话处理

| 变更                                    | 会话处理                                                 |
| --------------------------------------- | -------------------------------------------------------- |
| 房间密码（含同时改两种密码）            | 撤销全部在线、离线和握手会话，包括修改者和直接 DM 登录者 |
| 仅 DM 密码：最初用 DM 密码登录          | 全部撤销，即使已经降为普通玩家                           |
| 仅 DM 密码：房间密码登录的普通玩家      | 保持有效                                                 |
| 仅 DM 密码：房间密码登录后升级的在线 DM | 按当前连接建立顺序转普通席位，无名额者注销退出           |
| 仅 DM 密码：房间密码登录后升级的离线 DM | 撤销 DM 角色，保留原活动期限，恢复时按普通角色检查       |

改密不续期。成功持久化凭证后更新密码代次，旧异步校验结果不能建立新授权；失败不改变凭证或角色。到期、被踢、注销及改密失效 Token 不得调用受保护 API、资源或 WS。

## 数据边界

Config 不读取、持有或传递密码。启动组装层 `bootstrap.ts` 打开 MAIN 的 CredentialStore；房间服务只取得即时验密与修改方法。CredentialStore 是唯一凭证来源，不建立环境变量固定校验器。启动失败、正常关闭及监听失败均释放凭证持有的数据目录互斥；异常退出由操作系统释放。

Storage 只取得 `{ dataDir, images, resourceBytes, backup, parse }`，不读环境变量、不接触凭证。房间使用 schemaVersion 4，旧版本在加载与恢复时明确拒绝。备份有意包含 DM 私有说明及图片，不含凭证、会话令牌、玩家私人笔记、属性工具本机数据、音乐文件、音乐元数据或播放状态。私人笔记仅保存在玩家浏览器，活动消息不携带笔记内容。

新图片上传完整检查、解码和转码；棋子资源引用只检查 ID、存在性、字节、格式、动画页数和尺寸，不重复转码。编辑时引用不变则跳过图片处理。恢复仍沿用完整校验及重编码流程；ZIP 解压峰值内存和恢复重编码开销并仍然存在。图片与备份限额的唯一说明见 [配置](CONFIGURATION.md)。

## 密码管理与重置

密码策略由服务端统一执行，初始化、网页修改和重置共用：8–128 个 Unicode 码点；大写英文字母、小写英文字母、数字、特殊符号中至少两类；不含空白和控制字符。特殊符号按 Unicode 标点或符号分类。两种密码不能相同；网页修改的新值不能等于该项旧值。

常见弱密码表在 `src/server/weak-passwords.json`，按完整字符串忽略大小写匹配，不作子串拦截、不访问外部服务。这是小型本地名单，不是穷尽的强度评分。增补名单后重启生效；既有密码不会因名单更新而自动失效。

首次启动：部署者在 `.env` 提供符合策略的初始密码，服务创建凭证文件；也可在启动前执行重置命令直接初始化。示例值不可使用。凭证建立后可从 `.env` 移除两项初始密码，重启和重新发布不会用环境中的旧值覆盖凭证。凭证损坏时拒绝启动，不静默回退到初始密码。

网页操作：DM 工具箱 → 密码管理，再次输入当前 DM 密码，可单改房间口令、单改 DM 密码或同时修改。两项一起修改须全部验证通过并一起保存；保存失败保留原密码和权限。改密后的具体失效与降级规则见上方会话处理表。改密与工具箱解锁使用独立尝试限流，参数见上方会话合同。

忘记密码时，在 CMD、PowerShell 或其他交互终端进入项目目录：

1. 停止 SMALLTABLE 服务；前台运行可按 Ctrl+C，后台运行应停止对应服务。
2. 执行 `npm run password:reset`。
3. 按提示输入并确认两个新密码，输入不回显；Ctrl+C 取消。失败不修改原凭证。
4. 执行 `npm start` 或重新启动后台服务。

重置读取 `.env` 中的 `DATA_DIR`，但不要求知道旧密码；两种密码一起重设。只更新凭证，不改变桌面、素材或私人笔记；也可用于修复损坏的凭证文件。必须在交互式终端运行，不接受命令参数或管道传递密码。

凭证文件保存独立随机盐与 scrypt 哈希，不存明文，不进入桌面快照或 ZIP 备份。程序创建文件时请求仅当前用户可读写的权限；Windows 部署仍应通过目录 ACL 限制访问。

服务和重置命令共用操作系统管理的本机互斥：独占绑定一个由规范化真实数据目录路径生成的回环 TCP 端口（范围 10000–29999，仅 `127.0.0.1`）。该端点不提供管理 API，不需要公网放行，也不新增依赖。即使进程被强制终止，操作系统也会释放互斥，新进程可重新取得；运行中的服务仍阻止重置及同目录重复启动。

端口映射存在碰撞可能；如果另一个数据目录或无关程序恰好占用同一端口，会显示端口号并拒绝启动，不另选端口绕过互斥。需处理占用或在停机后迁移数据目录；HTTP 监听端口不要占用该运行锁端口。同机进程需使用相同网络命名空间与一致的目录视图，不支持跨容器命名空间或跨主机共享数据目录。

从 0.5.5 升级前先停止旧服务，不同时运行不同版本。旧 `credentials.lock` 若含已退出的 PID，新版本会清理；若 PID 仍存在、权限不足或文件内容无法识别，则拒绝启动并提示。PID 被其他进程复用或旧文件损坏时，需人工确认旧服务已停止后只删除旧锁文件。从 MAIN 0.5.6 起不再创建该锁文件，因此之后的崩溃不会产生此类文件残留。不要删除 `credentials.json` 来触发初始化。

HTTP 端口占用等监听错误会输出原始错误码（如 `EADDRINUSE`），完成服务和互斥清理后以非零状态退出。进程管理器可在原因排除后重试，不会被这次启动遗留的互斥挡住。

## 诊断

诊断仅含版本、时间、稳定错误码、连接状态、重试次数、epoch、revision、savedRevision。用户按需展开和复制；剪贴板失败可选中 textarea 手动复制。不包含 Cookie、口令、令牌、私有说明、笔记或完整房间。无遥测服务。

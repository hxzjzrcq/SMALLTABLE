# 当前 UI 维护

布局 src/client/App.tsx，主题与手机布局 src/client/styles.css，地图手势 Board.tsx，棋子表单 Inspector.tsx，先攻界面 InitiativePanel.tsx。网络调用统一通过 SmalltableClient。

先攻按钮位于属性工具左侧；每端显隐独立。先攻表仅名字、数字、修改、删除与排序方向。行编辑期间保留本地草稿，保存后按共享结果排序，同值保留原有顺序。不加入掷骰、轮次或 Token 绑定。

直线画笔在桌面工具栏，画笔模式显示颜色，DM 额外有清空按钮。鼠标/单指画线，双指缩放取消未完成线条。切回选择模式点线条可删除；线条位于棋子下层。未松开的线仅本机显示。

图片棋子显示图片和清晰短标记，以透明的完整占地区域承接指针事件，选中框保留；无图片棋子继续使用彩色形状。

选中棋子的 45° 旋转按钮只在选择模式显示。公开注释人人可编辑，公共棋子另开放棋面文字和归还；普通棋子其余字段仅 DM；创建棋子按钮在棋子侧栏。私人笔记本地保存。

手机玩家控件支持触摸，DM 编写仍面向电脑。角色卡管理只有提示占位；未经范围变更，不扩展为角色卡功能，也不引入自动战斗、所有权、撤销或拖动锁。DNDROLL 样式隔离，规则只调用 Core。

登录页单独维护：LoginPage.tsx + login/login.css + login/scene.js。仅替换登录场景，不修改桌面内部 UI。避免恢复样品的全局 html/body 样式、演示控件、inline script 或全局 window API。保留私人笔记入口；手机短屏和横屏优先表单。任何动画接入都必须支持减少动态效果、后台暂停和卸载清理。

Board 的非强制拆分建议见 [当前架构](ARCHITECTURE.md#随功能演进的维护建议非强制)，文档维护原则见 [README](../README.md#文档维护)。

DM 工具箱解锁后显示独立 PasswordSettings 折叠面板。修改需要再次输入当前 DM 密码，新密码重复确认；留空项不修改。提交期间禁用表单，完成或失败后清空密码输入。修改房间口令前确认全员断线；仅改 DM 密码后按认证来源撤销或降级，详见安全合同。服务端以 4003 关闭连接时，客户端清除房间视图和内存凭证，返回登录页并停止自动重连。具体密码策略与运维步骤见 [安全与密码管理](SECURITY.md#密码管理与重置)。

## 面板更新与本机状态

DicePanel 只接收骰点记录、名称和必要操作状态；InitiativePanel 只接收条目、排序方向和必要状态；DMPanel 只接收地图、网格、名称、在线管理列表、相关限额、连接和 DM 状态，保留 PasswordSettings。Notes 的字节上限由 App / LoginPage 传入，不订阅全局控制器、不自行请求配置。各面板使用 memo，关闭回调引用稳定。位置、旋转、公开注释增量不应执行无关面板；骰点、名单、先攻、限额及权限的相关变化仍更新。

侧栏骰盘、棋子、笔记和 DM 面板继续 hidden 挂载，保留草稿及滚动位置。先攻盘关闭仍卸载，未提交输入不保存，已提交条目留在共享数据中。属性工具首次打开后保持 iframe，关闭不丢会话。密码撤权或断线移除 DM 编辑器和密码表单；不得以更新优化阻挡状态传播。

棋子清单只比较 ID、顺序、名称、编号、颜色、形状、隐藏状态、公共身份、选中状态及数量限额，跳过坐标、旋转、注释等未显示字段变化。Inspector 两个编辑器按用途和 token.id 分别设置 key，不跟坐标重建。提交管理草稿时从控制器读取最新 x/y/angle 和公开注释，避免旧草稿覆盖刚发生的移动或公开编辑；Board 继续接收棋子的实际变化。

界面保留有操作意义的数量计数，像素与资源字节上限移到帮助；新增、复制、先攻添加、画线和名单保存按限额控制。图片上传前检查本机文件字节，格式/尺寸由服务端校验。笔记配置未取得时只读，仍可读取、复制和导出已有内容；超限写入保留最后有效内容。配置值与迁移见 [配置](CONFIGURATION.md)。

未使用的 DNDROLL BatchPanel 及其专用文案、样式已删除，Core 原有批量能力不变。登录装饰、布局、桌面样式和规则源码未改。

## 多地图、背景与掀桌

DM 工具箱“添加地图”按顺序新增并选中；原文件名仅作普通文本显示。列表可切换和删除，当前地图删除后选择剩余第一项，空列表显示空白桌面。背景缩放下拉为每图独立参数，与桌面“放大视图/缩小视图”的相机操作分离；不移动棋子、改变网格或测距。切图/背景缩放不自动重置相机，“查看全部”才重新适配。

“掀桌”只弹一次确认，明确删除普通棋子、归还并重置全部公共棋子及清空画线、不可撤销。取消不提交；成功后失效选择、拖动和画线预览清除。地图、网格、先攻、骰子、名单、私人笔记和音乐不受影响。

棋子图片仍先上传、后保存，取消编辑释放暂存。切换选中棋子或失去 DM 权限时释放未绑定引用；请求失败的暂存最终按固定期限清理。上传并不代表修改已保存，提交结果以上方房间保存状态和错误提示为准。

## 房间音乐

桌面上方显示服务器状态和本地状态；DM 展开音乐管理可上传 MP3、选择曲目播放、暂停全桌音乐、停止、删除。收起音乐管理不卸载播放器，不停止或重置 Audio；本机音量、静音及拒绝入口保留。上传不播放；没有重命名、排序或播放列表。

首次播放或切换到另一条目会产生新推送；A→B→A 重新询问。暂停/恢复以及停止后重播同曲保持推送 ID。停止进度归零但保留选曲；自然结束停止归零，不循环。删除当前条目停止并取消待处理提示，服务重启无当前曲目且不自动播放。

玩家接受前不设置音源；拒绝不下载。新推送替换旧提示且立即停止旧音频，旧提示点击不授权新推送。选择只保存在当前标签页，刷新/断线恢复，新标签页重新询问。音量和静音只作用本机。点击 DM 播放视为本人接受，不替其他人选择。

“本地”分别显示未接受、已拒绝、加载中、播放中、暂停、停止、受浏览器阻止或加载失败；全桌播放不等于本地成功。受阻时点击播放，加载失败时可点击重新加载。元数据就绪后按最新权威时间跳转，加载期间的暂停/停止/切曲以最新状态为准。同步目标及实测条件见 [本次验证](VALIDATION.md)。

内嵌购点使用适配层样式，窄屏将成本放到单独一行，保留按钮固定触控尺寸；未修改 DNDROLL Core 规则。

## 棋子克隆与本地选择

DM 在棋子清单每行可点“克隆”，可连续操作。单选编辑面板也使用相同克隆入口。克隆复制服务端最近同步的棋子字段，包括标签、名称、外观、占地、朝向、公开及 DM 私有说明，不复制尚未保存的编辑草稿。新棋子拥有独立 ID，复用图片文件，以世界坐标各偏移 24 的位置出现；接近正边界时向反方向偏移，不越界。之后移动、修改说明或删除互不影响。目录克隆收到成功快照后选中新棋子；失败不出现幽灵副本。达到普通棋子池配置上限时禁用按钮，服务端仍做最终检查。

选择/移动工具下，普通点击棋子替换选择，普通点击空白清空选择；Shift＋点击棋子加入或移出选中集合，Shift＋点击空白保持选择。仅松开 Shift 不清除多选。棋子清单使用相同的点击规则。Shift 选中不启动拖动，也不向服务器提交选择；不显示他人的选择，不保存或广播选择集合。

多选显示多个选中框及“已选 N 枚”；隐藏单枚棋子的编辑器和旋转入口。没有集体移动、旋转、编辑或克隆。普通点击原本选中的任一棋子也会回到单选，后续拖动仅移动这一枚。其他连接删除棋子时剔除失效 ID；断连、离开、房间 epoch 变化清除选择。克隆仅 DM 可执行；公共原件克隆为独立普通棋子，占普通额度且不保留 publicId。普通删除仅 DM 可执行，PL 可选择并归还公共棋子。隐藏棋子的克隆仍隐藏。

## 键盘快捷键

Delete 对当前有效选择弹出一次“删除选中的 N 枚棋子？不可撤销”确认。取消保留选择、不发删除请求；确认向服务端发一条批量命令。未连接、无有效选择或 PL 选择中包含非公共棋子时不生效。沿用图片引用回收，不增加素材库或撤销。

输入框、文本域、下拉框、可编辑内容、普通按钮、链接、iframe 或模态窗口中不触发。棋子目录的选择按钮明确允许 Delete，克隆按钮仍受保护。忽略组合键、输入法组合及长按重复事件。松开 Shift 后按 Delete；Shift＋Delete 不作为删除快捷键。点击桌面将键盘焦点交给桌面。当前没有按键配置界面。

统一入口 `src/client/shortcuts.ts` 负责监听、保护和卸载；App 绑定控制器命令。`selection.ts` 只处理本机选择转换，不持有 WebSocket。后续快捷键继续复用该入口。

## 登录与会话

登录页增加临时 ID，输入时不截断、不改写，允许中文组词；按共享校验显示单位数及最终提交错误。一个密码框接受房间密码或 DM 密码，服务器确定角色。密码提交后清空表单，控制器不缓存密码重试。

初始化自动检查 Cookie；有效时恢复 ID 与服务器角色。自动恢复无用户活动消息。网络故障最多十次退避重试；满员时尚无桌面者显示独立恢复页，提供“重试进入”和“退出当前会话”，不重新索要密码。ID 冲突、被踢、过期、改密和旧页被替代均停止自动重试。错误处理使用机器码，文案不决定重试行为。

顶部显示普通玩家在线数/上限及 DM 在线数/上限。工具箱显示在线 ID、角色与普通玩家踢人按钮，包含目标 ID 的一次确认；列表仅 DM 接收。锁定按钮旁说明“锁定后转为普通玩家；普通席位已满时将退出”。切换侧栏或收起面板不锁定；角色或连接变化会卸载 DM 草稿与管理内容。

“离开房间”主动注销；断网时提示“已在本地退出，服务器注销待联网完成”，联网后先注销。同一浏览器配置文件共用身份，多标签页新页接管旧页；旧页提示“此会话已在其他页面打开”。期限、改密及席位合同统一见 [安全](SECURITY.md#会话与席位)。

## 断线时的桌面生命周期（0.6.9）

| 原因                                                               | 桌面处理                                                                             |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| 临时网络故障、WebSocket 意外关闭                                   | 保留上次画面、普通面板草稿及属性工具 iframe；禁用联网操作并最多退避重试十次          |
| 十次自动重连失败                                                   | 保留桌面，明确提示重连失败，允许手动重试或离开                                       |
| 恢复时普通或 DM 席位已满                                           | 保留已有桌面，不自动重试，允许手动重试或离开；首次打开尚无桌面时显示恢复页及手动重试 |
| ID 冲突                                                            | 卸载桌面，回登录页，要求更换 ID 并重新登录，不提供原会话重试按钮                     |
| 会话过期、被踢、口令变更导致失效、降级无席位、会话被接管、主动退出 | 卸载桌面，停止自动重试，显示对应原因                                                 |

临时断线立即清除内存快照中的 DM 私有说明、在线管理列表、DM 编辑器及管理草稿；重连后的权限和数据以服务端快照为准。音乐断线停止并移除音源。选择与拖动预览仍在断线时清除。保留现场不延长会话、不排队提交离线操作；私人笔记及独立属性工具仍可本地使用。

## 独立恢复页与公共投骰理由（0.7.0）

初始状态先显示恢复检查，避免在 Cookie 检查前闪现登录表单。无有效会话最终显示登录页；有效会话依次检查、连接及同步桌面。已有桌面时不显示恢复页，仍按上表保留或清理。网络十次重连失败或满员时提供手动重试与退出；终止错误回登录并显示原因。认证、连接/首快照超时均进入既有失败处理。LoginShell 共用原地城动画、Notes 入口与版本号，卸载清理不另建一套动画。

骰盘输入先按完整原骰式解析；失败后从末尾寻找最长有效骰式前缀。理由独立验证、保存并按普通文本展示，最多 32 个 Unicode 码点；旧记录缺少 reason 可读。快捷骰子直接投掷、不附输入框中未提交的理由。完整规则见 shared/roll-input.ts 与 model.ts；不增加聊天入口。

## 棋子面板与定位

公共盒位于棋子面板；A–Z 按可取用/桌上区分。临时文字不改变公共身份，列表显示“字母 · 临时文字”；选中公共对象只开放改字、旋转、归还，列表提供定位，DM 另可克隆。普通隐藏/显形放在列表“操作”中。隐藏对象在 DM/PL 桌面均不渲染文字、图片、框或控件，也无命中区域；定位隐藏对象仍不显形。

PC 双击条目及所有终端点击“定位”将对象中心移至本地视口中心，不改棋子或其他人相机。创建普通或取用公共棋子复用 Board 当前相机与实际可见尺寸计算世界中心，并限制在世界边界；连续创建与公共取用共用本机放置序列，按屏幕最多 24px 的步幅错开，靠近边界时向可见空间内排列。49 个位置后循环；相机、视口尺寸、地图或 epoch 改变后重置。克隆继续邻近原件。

所有 label 共用 1–4 Unicode 码点校验，去首尾空白，拒绝空白内容、换行与控制符；不静默截断，输入法组合期间不提交。字号随长度变化。name、note、secret 的长度不变。昵称沿共享中英权重规则，最大 16 单位。

最终移动预览由控制器关联 moveId，普通广播不取消它；成功/拒绝回执及 2 秒超时结束等待，较旧回执不得覆盖后续移动。隐藏、删除、归还、换图、epoch、断线、取消和卸载清理临时交互，迟到回执不复活对象。完成初始/恢复快照之前不开放网络修改。

地图、棋子图、MP3、ZIP 上传显示真实字节进度；无法取得时不定进度。传输完成后为服务器处理中，成功响应才显示完成；失败可重试，同入口请求未完成不重复提交。错误先显示中文，诊断按需展开复制，失败可手选文字。

# 当前 UI 维护

布局 src/client/App.tsx，主题与手机布局 src/client/styles.css，地图手势 Board.tsx，棋子表单 Inspector.tsx，先攻界面 InitiativePanel.tsx。网络调用统一通过 SmalltableClient。

先攻按钮位于属性工具左侧；每端显隐独立。先攻表仅名字、数字、修改、删除与排序方向。行编辑期间保留本地草稿，保存后按共享结果排序，同值保留原有顺序。不加入掷骰、轮次或 Token 绑定。

直线画笔在桌面工具栏，画笔模式显示颜色，DM 额外有清空按钮。鼠标/单指画线，双指缩放取消未完成线条。切回选择模式点线条可删除；线条位于棋子下层。未松开的线仅本机显示。

图片棋子只显示图片，以透明的完整占地区域承接指针事件，选中框保留；无图片棋子继续使用彩色形状。

选中棋子的 45° 旋转按钮只在选择模式显示。公开注释人人可编辑，其余棋子字段仅 DM；创建棋子按钮在棋子侧栏。私人笔记本地保存。

手机玩家控件支持触摸，DM 编写仍面向电脑。角色卡管理只有提示占位；未经范围变更，不扩展为角色卡功能，也不引入自动战斗、所有权、撤销或拖动锁。DNDROLL 样式隔离，规则只调用 Core。

登录页单独维护：LoginPage.tsx + login/login.css + login/scene.js。仅替换登录场景，不修改桌面内部 UI。避免恢复样品的全局 html/body 样式、演示控件、inline script 或全局 window API。保留私人笔记入口；手机短屏和横屏优先表单。任何动画接入都必须支持减少动态效果、后台暂停和卸载清理。

Board 的非强制拆分建议见 [当前架构](ARCHITECTURE.md#随功能演进的维护建议非强制)，文档维护原则见 [README](../README.md#文档维护)。

DM 工具箱解锁后显示独立 PasswordSettings 折叠面板。修改需要再次输入当前 DM 密码，新密码重复确认；留空项不修改。提交期间禁用表单，完成或失败后清空密码输入。修改房间口令前确认全员断线；仅改 DM 密码后工具箱重新锁定。服务端以 4003 关闭连接时，客户端清除房间视图和内存口令，返回登录页并停止自动重连。具体密码策略与运维步骤见 [安全与密码管理](SECURITY.md#密码管理与重置)。

## 面板更新与本机状态

DicePanel 只接收骰点记录、名称和必要操作状态；InitiativePanel 只接收条目、排序方向和必要状态；DMPanel 只接收网格、名称、相关限额、连接和 DM 状态，保留 PasswordSettings。Notes 的字节上限由 App / LoginPage 传入，不订阅全局控制器、不自行请求配置。各面板使用 memo，关闭回调引用稳定。位置、旋转、公开注释增量不应执行无关面板；骰点、名单、先攻、限额及权限的相关变化仍更新。

侧栏骰盘、棋子、笔记和 DM 面板继续 hidden 挂载，保留草稿及滚动位置。先攻盘关闭仍卸载，未提交输入不保存，已提交条目留在共享数据中。属性工具首次打开后保持 iframe，关闭不丢会话。密码撤权或断线移除 DM 编辑器和密码表单；不得以更新优化阻挡状态传播。

棋子清单只比较 ID、顺序、名称、编号、颜色、形状、选中状态及数量限额，跳过坐标、旋转、注释等未显示字段变化。Inspector 两个编辑器按用途和 token.id 分别设置 key，不跟坐标重建。提交管理草稿时从控制器读取最新 x/y/angle 和公开注释，避免旧草稿覆盖刚发生的移动或公开编辑；Board 继续接收棋子的实际变化。

有效限额在工具栏、各面板和图片提示中显示；新增、复制、先攻添加、画线和名单保存按限额控制。图片上传前检查本机文件字节，格式/尺寸由服务端校验。笔记配置未取得时只读，仍可读取、复制和导出已有内容；超限写入保留最后有效内容。配置值与迁移见 [配置](CONFIGURATION.md)。

未使用的 DNDROLL BatchPanel 及其专用文案、样式已删除，Core 原有批量能力不变。登录装饰、布局、桌面样式和规则源码未改。

## 多地图、背景与掀桌

DM 工具箱“添加地图”按顺序新增并选中；原文件名仅作普通文本显示。列表可切换和删除，当前地图删除后选择剩余第一项，空列表显示空白桌面。背景缩放下拉为每图独立参数，与桌面“放大视图/缩小视图”的相机操作分离；不移动棋子、改变网格或测距。切图/背景缩放不自动重置相机，“查看全部”才重新适配。

“掀桌”只弹一次确认，明确清空全部棋子及画线、不可撤销。取消不提交；成功后失效选择、拖动和画线预览清除。地图、网格、先攻、骰子、名单、私人笔记和音乐不受影响。

棋子图片仍先上传、后保存，取消编辑释放暂存。切换选中棋子或失去 DM 权限时释放未绑定引用；请求失败的暂存最终按固定期限清理。上传并不代表修改已保存，提交结果以上方房间保存状态和错误提示为准。

## 房间音乐

桌面上方显示服务器状态和本地状态；DM 展开音乐管理可上传 MP3、选择曲目播放、暂停全桌音乐、停止、删除。上传不播放；没有重命名、排序或播放列表。

首次播放或切换到另一条目会产生新推送；A→B→A 重新询问。暂停/恢复以及停止后重播同曲保持推送 ID。停止进度归零但保留选曲；自然结束停止归零，不循环。删除当前条目停止并取消待处理提示，服务重启无当前曲目且不自动播放。

玩家接受前不设置音源；拒绝不下载。新推送替换旧提示且立即停止旧音频，旧提示点击不授权新推送。选择只保存在当前标签页，刷新/断线恢复，新标签页重新询问。音量和静音只作用本机。点击 DM 播放视为本人接受，不替其他人选择。

“本地”分别显示未接受、已拒绝、加载中、播放中、暂停、停止、受浏览器阻止或加载失败；全桌播放不等于本地成功。受阻时点击播放，加载失败时可点击重新加载。元数据就绪后按最新权威时间跳转，加载期间的暂停/停止/切曲以最新状态为准。同步目标及实测条件见 [本次验证](VALIDATION.md)。

内嵌购点使用适配层样式，窄屏将成本放到单独一行，保留按钮固定触控尺寸；未修改 DNDROLL Core 规则。

## 棋子克隆与本地选择

DM 在棋子清单每行可点“克隆”，可连续操作。单选编辑面板也使用相同克隆入口。克隆复制服务端最近同步的棋子字段，包括标签、名称、外观、占地、朝向、公开及 DM 私有说明，不复制尚未保存的编辑草稿。新棋子拥有独立 ID，复用图片文件，以世界坐标各偏移 24 的位置出现；接近正边界时向反方向偏移，不越界。之后移动、修改说明或删除互不影响。目录克隆收到成功快照后选中新棋子；失败不出现幽灵副本。达到实际配置的棋子数量上限时禁用按钮，服务端仍做最终检查。

选择/移动工具下，普通点击棋子替换选择，普通点击空白清空选择；Shift＋点击棋子加入或移出选中集合，Shift＋点击空白保持选择。仅松开 Shift 不清除多选。棋子清单使用相同的点击规则。Shift 选中不启动拖动，也不向服务器提交选择；不显示他人的选择，不保存或广播选择集合。

多选显示多个选中框及“已选 N 枚”；隐藏单枚棋子的编辑器和旋转入口。没有集体移动、旋转、编辑或克隆。普通点击原本选中的任一棋子也会回到单选，后续拖动仅移动这一枚。其他连接删除棋子时剔除失效 ID；断连、离开、房间 epoch 变化清除选择。克隆和删除仅 DM 可执行；普通玩家可以本地选择和正常移动棋子。

## 键盘快捷键

Delete 对当前有效选择弹出一次“删除选中的 N 枚棋子？不可撤销”确认。取消保留选择、不发删除请求；确认向服务端发一条批量命令。未连接、无有效选择或非 DM 不生效。沿用图片引用回收，不增加素材库或撤销。

输入框、文本域、下拉框、可编辑内容、普通按钮、链接、iframe 或模态窗口中不触发。棋子目录的选择按钮明确允许 Delete，克隆按钮仍受保护。忽略组合键、输入法组合及长按重复事件。松开 Shift 后按 Delete；Shift＋Delete 不作为删除快捷键。点击桌面将键盘焦点交给桌面。当前没有按键配置界面。

统一入口 `src/client/shortcuts.ts` 负责监听、保护和卸载；App 绑定控制器命令。`selection.ts` 只处理本机选择转换，不持有 WebSocket。后续快捷键继续复用该入口。

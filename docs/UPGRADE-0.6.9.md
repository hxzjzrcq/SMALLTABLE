# 0.6.9 升级

以交付的 SMALLTABLE 0.6.8 完整源码 ZIP 为唯一基线。未修改房间 schema（仍为 3）、存档结构、DNDROLL Core 源码或配置默认值。

- 修复开发代理：API、图片与音频保留 Host；增加 `/audio` 代理，WebSocket 保持既有转发。
- 临时断线保留桌面、普通草稿和属性工具；清除 DM 私有数据与管理草稿。三次重连失败或满员可手动重试。完整卸载规则见 [UI](UI.md#断线时的桌面生命周期069)。
- ID 冲突返回登录页，明确换 ID 重新登录，不提供原会话重试按钮。
- 登录、工具箱解锁、改密分别限流；保留按 TCP 对端 IP 计数，代理下仍可能共用各桶。不增加可信代理配置。
- `tsx` 从开发依赖移至生产依赖；无新增或升级依赖。完整安装并构建后，可仅安装生产依赖启动。见 [部署](DEPENDENCIES.md)。

升级前停止旧服务，保留原数据目录和配置；安装依赖并执行 `npm run build` 后启动。既有内存会话不跨进程重启保留。未推送 GitHub或部署。

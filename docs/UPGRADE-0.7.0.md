# 0.6.9 → 0.7.0 升级

唯一源码基线为 `SMALLTABLE-2026-10-22-v0.6.9-完整源码.zip`。SHA-256 见根目录 `BASELINE.json`；未混合其他版本或 GitHub 代码。

## 本次变化

- 刷新时显示独立恢复页，区分会话检查、连接、同步与手动重试。复用原登录装饰、样式及动画清理；原登录表单与布局保留。已有桌面临时断线仍保留公开现场，立即撤除 DM 敏感内容。终止错误回登录。认证与首个快照分别设 15 秒等待上限，快照到达才重置自动重试计数。
- 公共骰式可附空格分隔的理由，例如 `1d20 + 5 侦查陷阱`。独立 reason 字段，最多 32 个 Unicode 码点，首尾空白不计；拒绝换行、控制字符及不配对代理字符。先解析完整骰式，再尝试最长有效前缀；随机计算器源码不变。理由按文本同步、保存及备份；schemaVersion 仍为 3，可读无理由的旧记录。
- 登录/恢复页版本直接读取根 package.json，构建后随前端产物发布。
- 项目根目录固定 `START-SMALLTABLE.cmd`。与本次上传脚本相比，仅将私人公网地址和 Cpolar 专用提示改为通用穿透/反代提示；移除专用管理页提示。工作目录、3000 端口检查、依赖检查、npm start、失败与退出逻辑不变。脚本不含个人域名、密码或令牌；个人部署信息留在自己的配置中。

## 交付与覆盖

完整包含源码、前端 dist、Core 产物、测试和文档。增量包根目录直接对应部署根目录，只包含新增或变化文件及本次所需构建产物，不套项目文件夹。

补丁不含 `.env`、`data/`、`smalltable.config.json`、node_modules 或穿透程序/配置。没有新增、升级依赖；已有 0.6.9 依赖可继续使用，无须重新安装。完整包首次使用仍需 npm ci，设置自己的 .env；首次构建不必重复执行，因为包含 dist。

1. 停止服务。备份现有整个程序目录及数据，不在运行过程中覆盖文件。
2. 手动核对原 package.json 的版本为 0.6.9，确认来源是上述基线。`PATCH-0.7.0.json` 列出覆盖文件原始/目标哈希；没有自动安装器，不会自动阻止误装。
3. 将补丁全部内容解压到部署根目录，允许覆盖。保留自己的配置、数据、依赖和穿透文件。
4. 用固定 CMD 启动。若文件已存在，此次用通用版替换；今后可保持快捷方式不变。启动时仍检查本机 3000 端口，避免重复实例。
5. 在本机刷新，确认版本 v0.7.0，登录、恢复、投骰理由与多人同步正常。再由用户在自己的穿透地址验收。
6. 异常时停止服务，恢复备份的程序目录及对应依赖。包含理由的新记录不能由旧软件可靠读取，回退到 0.6.9 时应同时恢复升级前的数据备份，并另存当前数据以免丢失升级后的操作。

覆盖后旧的带哈希 dist 文件可能留在磁盘，但新 index.html 只引用本次构建，旧文件不参与运行。无需删除数据或配置。

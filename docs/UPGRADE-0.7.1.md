# 0.7.1：保守精简与公开源码包

唯一基线为 SMALLTABLE-0.7.0-完整源码.zip，未混入历史版本代码。业务行为、房间 schema 3、依赖版本与 Core 规则源码保持不变。

- 复用密码表单空值常量和浏览器活动事件清单。
- 合并浏览器测试基础启动配置与登录提交步骤，保留各场景特殊参数、导航和等待。
- 合并 React DOM 测试的原生输入更新步骤，保留 act、事件及原有断言。
- 删除经编译器检查确认未使用的测试导入与局部变量。
- 保留不同房间夹具：其密码、配置和生命周期约定不同，本次不强行合并为通用框架。
- 提供通用 START-SMALLTABLE.cmd 与根目录帮助.md；通用 CMD 不再固定检查 3000，也不强制要求 .env，支持使用者的端口及环境变量部署。服务端继续检查配置、真实监听端口及数据目录互斥。
- 私人启动脚本单独交付，不进入公开 ZIP；公开脚本不包含个人部署地址或秘密。

升级前停止服务、备份完整数据和配置。推荐新目录解压，迁入自己的 .env、JSON 与数据目录，执行 npm ci、npm run build 后启动。不要同时运行新旧服务。首次安装和发布方法见 [设置帮助](../帮助.md)。

减行统计及实际验证见 [验证记录](VALIDATION.md)。没有设置强制减行比例，没有删除测试场景。

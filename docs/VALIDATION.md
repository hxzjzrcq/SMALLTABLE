# SMALLTABLE 0.5.6 验证记录

基线：SMALLTABLE 0.5.5。修改数据目录运行互斥、服务启动/失败清理，并整理文档；密码规则、房间协议与前端功能不变。

## 本轮结果

- `npm run format`、`npm run build`：通过。前端重新构建，输出与 0.5.5 一致。
- `npm test`：50 项全部通过。包含原有房间、备份、密码管理、客户端行为，以及新增生命周期测试。
- 生命周期专项：同目录及路径别名拒绝重复运行；不同目录可独立运行；5 个进程同时竞争只有 1 个取得互斥；强制终止持有者后可以立即重新取得。
- 实际服务入口：SIGKILL 后重启成功，原凭证保留；HTTP 端口被占时报告原始 `EADDRINUSE`、释放互斥并非零退出，解除端口占用后同目录启动成功。
- 初始化失败释放互斥；旧版 PID 锁的活进程保护、已退出 PID 清理和无法识别的锁文件拒绝处理均通过。
- 文档整理：历史交接归入 `docs/history/` 并标注历史语境；UI 当前指南改为 `docs/UI.md`；当前入口及测试选择不再依赖旧版本交接。

无新增外部依赖；房间 schemaVersion 仍为 2；DNDROLL Core 保持原样。本轮没有增加版本交接文档。

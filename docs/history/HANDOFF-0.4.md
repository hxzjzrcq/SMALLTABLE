# SMALLTABLE 0.4.0 交接

> 历史记录，不作为当前维护指令；当前入口见 [README](../../README.md)。本文中的“当前”“本轮”和操作指令仅指当时版本。文中 `VALIDATION.md` 指当时的验证记录，现已由当前版本记录替换。

基线：SMALLTABLE-v0.3.0-完整源码.zip（干净主线）。没有合并 Kimi 阶段发布适配，不含专用启动器、服务端 bundle 或随包原生依赖；未部署。

## 本轮变更

- DNDROLL 移除批量面板及入口。Core、批量算法与来源哈希保持原样，其他属性生成流程保留。
- 仅选中棋子时，在棋子上方显示顺时针 45° 小按钮。按钮为独立 HTML 控件，点击不会进入地图拖动；位置随视角、棋子移动及方形旋转边界更新，触控区域 32px。
- 所有玩家都能编辑任意棋子的公开注释。独立 `note` 指令只接收 id、note、epoch，严格拒绝额外字段；4096 UTF-8 字节上限。服务端校验桌面代次，只变更 note，继续按角色投影、广播与保存。
- DM 其他棋子编辑提交时保留服务器最新公开注释，避免旧表单覆盖玩家更新。未保存的注释草稿不会被同步快照覆盖；同一公开注释仍以最后提交为准，无协同文本合并。
- “＋ 无图片棋子”从桌面工具栏移入“棋子”侧面板，只有解锁 DM 后可见。
- 主项目版本为 0.4.0；adm-zip 0.6.1、sharp 0.35.5 保留。锁文件内旧私有镜像 URL 改为 npm 官方 registry，版本及完整性校验未变。

## 当前边界

图片上传限制、地图视角、刷新登录状态、正式部署密码与代理配置均不属于本轮。用户复测确认地图同步正常，勿再按同步缺陷修改。公网正式部署仍须独立收尾，不要直接沿用 Kimi 临时发布快照。

房间 schemaVersion 仍为 1，备份结构不变；旧客户端不提供公开注释编辑入口，新客户端应与本版本服务端配套。私人笔记仅在浏览器；DM 私有字段不进入玩家消息。

## 验收

执行记录见 VALIDATION.md。建议人工用电脑 DM + 手机玩家：选择棋子点 ↻；两端编辑公开注释并观察同步；玩家确认无 DM 编辑控件；DM 在棋子面板创建棋子；打开属性工具确认批量面板消失。

# 0.7.2 实现记录

需求原文单独保存为根目录 SMALLTABLE-0.7.2-更新任务书.md。以下描述实现；执行结果归 VALIDATION.md，审查归 REVIEW-0.7.2.md。

| 范围                   | 实现位置与选择                                                                                                                                                                                     |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 结构、文字、数量、存档 | shared/model.ts 统一 schema 4、publicId、hidden、label 和命令约束。只保存一份在桌 tokens 状态；盒中 A–Z 由差集推导。普通池/公共池分别验证，总量为配置普通上限加 26。                               |
| 公共盒与隐藏           | server/app.ts 沿用权限登记、串行队列和候选保存；public.take、token.label、token.hidden；PL 删除混入普通或未知对象整体拒绝。隐藏不释放图片引用。                                                    |
| 创建、克隆、定位       | Board 通过本机相机和实际可见尺寸给 App 提供中心/定位；已有克隆创建路径剥离 publicId 并检查普通额度，隐藏状态保留。列表可点击定位，PC 同时支持双击。                                                |
| 拖动                   | Board 负责活动手势；controller.pendingMoves 只保存松手等待回执的位置与 moveId。广播不取消预览，回执带 epoch/revision/结果/权威坐标；连接代次隔离迟到消息，2 秒超时，后续 revision 不被旧回执覆盖。 |
| 会话                   | Sessions 独立断线截止时间；在线不按活动过期，断线释放席位，失败恢复不延期。心跳漏回三次终止；Cookie 在线续期且只以 HttpOnly 接入浏览器认证。客户端十次有上限退避，完整快照后开放修改并重置次数。   |
| 上传                   | controller 统一 XMLHttpRequest 真实进度与响应阶段；每个入口防重复。UploadStatus 在四种现有上传入口展示状态、文件名与失败上下文。                                                                   |
| 音乐/界面/诊断         | 音乐管理 details 收起不卸载 Audio；数量保留，技术预算移到帮助。公共盒与操作放现有棋子面板；所有视口提供侧栏收起；诊断只按固定白名单生成，剪贴板失败可手选。                                        |
| 公开交付               | 版本、帮助、现行合同、开发导读、验证及校验清单同步。公开通用 CMD 不含个人部署内容。保留必要 dist/Core 构建产物，不含运行数据、依赖目录或私人配置。                                                 |

DNDROLL Core 规则未修改，没有增加框架、数据库、账号、所有权或第二套引擎。保留原有备份排除音乐、私笔记及凭证的规则；本版未实现旧 schema 迁移。

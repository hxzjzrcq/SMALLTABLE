# 0.7.2 执行方审查记录

这是执行方完成实现后的自审记录，未另行使用独立审计者。需求、实现、验证分别见原任务书、IMPLEMENTATION-0.7.2.md、VALIDATION.md。

- 核对 schema/命令/权限/加载/ZIP 共用边界：A–Z 身份唯一，公共无图、不可隐藏、固定外观，普通池与公共池分开计数；PL 混合删除整体拒绝。没有以界面显隐代替服务器授权。
- 核对候选提交：取用、归还、创建/克隆、改字、隐藏/显形保存成功后生效；注入保存失败时原内存与存档保留。移动回执只确认服务器接受，与 savedRevision 分开。
- 核对隐藏后的图形、命中、选中控件及拖动临时状态清理；服务端对所有角色拒绝隐藏对象移动/旋转。资源引用收集仍遍历全部 tokens，不以是否渲染作为回收条件。
- 核对公共克隆剥离 publicId、独立普通身份与额度，保留隐藏普通对象的 hidden；投影不因新增字段或回执绕过 secret 过滤。
- 核对会话在线/离线分离、固定断线截止、不重复延期、短期占位与恢复时席位/重名检查，既有注销/踢人/改密/替换语义保留。浏览器登录/恢复响应不再包含令牌，Cookie 为 HttpOnly。
- 核对回执关联 moveId、epoch、连接代次及 revision；旧回执/旧定时器不清新预览，后续有效移动优先。超时、隐藏、删除、归还、换图、断线及卸载清理。
- 核对 label Unicode 码点与控制符、昵称权重，输入法期间不提交，远端公共改字不重建本地脏草稿。相机出生在视口和世界交集中；视口完全在界外则提示，不在看不到的位置生成。
- 核对上传实际进度与处理响应区分、入口防重复、失败后可重试；诊断只包含固定白名单，不含文件内容、凭证、笔记或 DM 私有说明。
- 比对指定基线：packages/dndroll-core 全部文件字节一致，依赖定义与锁文件依赖条目一致（根版本号除外）。证据见 validation-0.7.2/source-review.json。公开 CMD 为通用内容，版本为 0.7.2，保留 CRLF。

尚未执行真机、Windows CMD、目标公网/穿透和长期实机运行检查。浏览器触屏/视口模拟、时钟推进、故障注入及本机同步结果不能替代这些环境，详细边界见 VALIDATION.md。

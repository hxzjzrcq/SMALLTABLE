# SMALLTABLE 0.6.5 升级（2026-10-22）

唯一基线：`SMALLTABLE-0.6.1-完整源码.zip`。SHA-256：

`89cf3415d2b04b5a164f476d954994ddd582ba5c495862421378d98debf0fb28`

目标版本 0.6.5，实际交付日期 2026-10-22。未从 GitHub 或其他 ZIP 取源码；无推送、部署或线上数据操作。

软件版本与房间 schema 分开管理：当前 schema 3，旧 schema 1/2 在启动和恢复时拒绝，不迁移、不静默清空或覆盖。使用新数据目录进行本地测试；保留旧目录及旧版程序以备自行回退，不能将旧 room.json 直接交给新版继续运行。凭证仍由独立凭证存储管理，不进入房间文件或备份。

功能更新：内嵌购点窄屏修复；多地图及独立背景缩放；统一空间边界与查看全部；掀桌；图片/音乐总预算与短期图片暂存；MP3 库及全桌播放控制。具体规则分别归配置、架构、UI 文档，不在本页复制。

音乐库与音频独立持久化，不进入房间 ZIP；房间恢复保留当前音乐。需要自行归档音乐时，应离线备份对应目录和 music.json，此次未增加音乐备份界面。

安装：`npm ci`，按 README 初始化测试凭证，`npm run build`，`npm start`。前端 dist 和 Core 浏览器产物来自本次构建。验证记录含真实执行命令、结果及验收对应表；未测试平台不记通过。

## 代码整理

复用 SmalltableClient、共享 schema/权限登记、串行队列、Storage 图片管线、原子文件保存与原日志格式。新增 shared/music.ts 定义音乐状态，server/music.ts 管库和播放基准，server/mp3.ts 解析帧和时长，MusicPanel 管本地媒体与选择；camera.ts 集中查看全部。资源暂存/计量/回收留在 Storage，不建立第二套保存或网络控制器。DNDROLL Core 源码和规则未改；仅修改嵌入适配 CSS。

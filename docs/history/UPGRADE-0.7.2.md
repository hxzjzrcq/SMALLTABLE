# SMALLTABLE 0.7.2 更新说明

唯一源码基线：SMALLTABLE-0.7.1-完整源码.zip。未混入其他版本或 GitHub 提交。

## 本版行为

- 公共棋子盒固定 A–Z 26 枚，与默认 255 普通棋子分别计数；人人可取用、改字、旋转、归还。归还/掀桌重置公共状态；DM 可克隆为独立普通副本。
- 普通棋子可由 DM 在条目操作中隐藏/显形。隐藏后所有桌面均无图形、文字或命中区域，仍保留列表、坐标与额度；任何角色都不能移动或旋转隐藏对象。状态进入存档和 ZIP。
- 棋面文字为 1–4 Unicode 码点，四字符适配字号，完整名称与说明长度不变。昵称提升到 16 加权单位，汉字占 2，ASCII 字母数字占 1。
- 新建普通/取用公共棋子出现在发起者实际视口中心；列表双击或点击定位只调整本机相机，隐藏对象定位不会显形。
- 松手发送独立 moveId，最终预览等待匹配回执。普通广播不充当确认；旧回执不清新预览，2 秒超时退回最近权威位置。回执接受与落盘成功分开。
- 地图、棋子图、MP3、ZIP 上传显示真实进度、服务器处理、完成或失败，同入口防重复。失败显示文件名和原因，可重新选择原文件重试。
- 健康在线不因无操作退出；断线从服务端确认起有固定 45 分钟恢复资格，释放在线席位。每 10 秒心跳，连续三次漏回才断开；最多十次自动重连，退避上限 8 秒，完整快照后重置。浏览器凭证只通过 HttpOnly Cookie，不在登录/恢复 JSON 中返回。
- 音乐管理可收起且播放器独立继续播放。数量和错误提示保留，常驻像素/字节预算移到帮助。错误按需展开脱敏诊断，复制失败可手动选择文字。
- 公开包保留通用 START-SMALLTABLE.cmd；本次不修改私人脚本，不推送、不部署。

## 升级与数据

当前 schemaVersion 为 4，不兼容 schema 3，不增加迁移链。停止旧服务并完整保留旧程序、data、配置和旧备份。请在新目录解压，使用新的空 DATA_DIR 启动 0.7.2；旧数据继续用旧程序读取。不要直接用新版本覆盖或清空旧数据。

旧磁盘存档会明确拒绝启动；旧 ZIP 会拒绝恢复并保留当前房间。备份继续包含 DM 私有说明与图片，不包含密码、会话、私人笔记或音乐。音乐库仍独立保存。0.7.2 的公共/隐藏状态可在本版保存、重启和 ZIP 恢复。

依赖版本及 DNDROLL Core 规则未作更新。安装、构建、启动见根目录帮助与 README；当前测试结果、故障注入和未执行项目见 VALIDATION.md。

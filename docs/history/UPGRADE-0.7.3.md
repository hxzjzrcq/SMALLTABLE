# SMALLTABLE 0.7.3 修订

以 SMALLTABLE-0.7.2-完整源码.zip 为唯一基线，仅处理两项 P2 审计意见：

- 普通棋子创建与公共盒取用共用客户端放置序列，连续操作时小幅错开。可见范围及世界边界计算见 camera.ts；相机或桌面范围改变后从新中心开始。
- 玩家批量归还跳过已经不存在的 ID，继续归还其余公共棋子；混入仍存在的普通棋子时整体拒绝。全部 ID 已消失时返回当前快照，不增加 revision。

未修改待移动回执预览的清理机制（P3）。schema 仍为 4，无新依赖；0.7.2 数据与配置可继续使用。通用 CMD 和设置帮助保留，不加入私人部署信息。

停止旧进程并备份后更新源码，执行 npm ci、npm run build，再启动。此前版本的 schema 边界仍见 [0.7.2 升级](UPGRADE-0.7.2.md)。本次执行命令、结果及限制见 [验证](VALIDATION-0.7.3.md)。

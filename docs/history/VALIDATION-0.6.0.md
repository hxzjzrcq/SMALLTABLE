## 覆盖的关键行为

- 授权登记与 schema 命令完整对应，玩家/DM 权限清单符合要求；未知动作（包括原型名称）对 DM 也拒绝。HTTP 登记包含 passwords，health 和 media 匿名拒绝，config/login 的既有公开入口保留。
- 真实 WS 中玩家直接提交管理动作被拒绝且 revision 不变；真实 HTTP 管理入口验证权限。锁定、断线、改密使排队中的图片、备份、恢复、改密及 WS 管理命令不能执行，房间状态不变。
- 普通玩家快照/棋子增量不含 DM 私有说明；配置、公开响应、快照和房间 ZIP 不含实际密码、盐、哈希或会话令牌。备份有意包含 DM 私有说明；私人笔记测试确认仅本机存储、活动及命令不携带笔记草稿。
- 密码策略、随机盐持久化、重启保留、旧环境值不覆盖、损坏凭证拒绝初始化、写盘失败不部分生效、并发改密和旧口令登录代次防护均通过；备份恢复不覆盖独立凭证。客户端 4003 清理及停止旧口令重连的 MAIN 测试保留并通过。
- 部分配置、独立集合上限、非法字段/数值、派生溢出及旧限额环境变量迁移错误通过。实际接入 17 个连接；260 棋子、261 先攻、262 线条、263 骰点记录及 600 个长名称经命令、磁盘和恢复通过；长名单消息超过旧 64 KiB。261 个 ZIP 条目恢复通过，未保留旧 257 条目硬上限。
- 图片未换引用的编辑不执行图片检查或转码；创建及更换引用只检查不转码；新上传仍转码和去重。非法 ID、缺失文件、无效图片、动画、文件字节/尺寸越界拒绝。磁盘读取检查当前房间与图片限制；备份路径、伪造展开大小、原子保存、保存失败恢复和 schema 1 迁移均通过。
- 实际组件函数计数：连续 25 次位置事件，DicePanel、Notes、打开的 InitiativePanel、DMPanel、TokenList 的额外执行次数各为 0；棋子位置更新到 25。旋转和公开注释增量同样不执行这些面板。骰点、名称、先攻、笔记限额、棋子名称/编号/颜色和权限相关变化仍更新。
- 骰子表达式、私人笔记、先攻未提交输入、棋子两类草稿、密码管理草稿及侧栏滚动位置在位置事件中保留；管理草稿提交使用最新坐标。DM 撤权和断线穿过 memo 边界，移除私有编辑器和密码表单。先攻关闭仍卸载并清除未提交输入，重新打开保留已保存条目；属性工具 iframe 的原有会话保留测试通过。

## 离线终端专项

可在支持 Unix PTY 的系统中执行 `python3 test/terminal-reset.pty.py`；仅使用 Python 标准库，不是 npm test 的依赖。专项实际验证：离线初始化的四次密码输入不回显；确认不一致不改凭证；Ctrl+C 取消；服务运行时重置被互斥拒绝且凭证不变；非交互管道输入被拒绝。

## 验收复核与修正

核查了共享 schema、HTTP/WS 权限清单、入队后授权、Storage 引用收集、恢复配额和媒体选择的数据流。修正了异步清理尚未完成就核对容量的时序、错误备份先撞限流的弱验证，以及 DM 选择必须绑定服务端返回的具体推送。提示按推送 key 更换，旧提示事件不会授权新曲目。清理失败保持实际文件计量；候选保存失败不发布为成功。

Core 原始源码哈希测试通过；未修改其规则算法。恢复/掀桌复用现有 epoch，未重建整房间；相机变更只作用视图。没有引入音频服务器、数据库、自动播放列表、撤销或场景隔离。

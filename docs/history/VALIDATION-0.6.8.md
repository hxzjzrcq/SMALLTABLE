## 失败、修复与复核

首轮完整套件为 103 项、98 通过、5 失败：3 项既有资源测试未显式配置多个 DM 名额；1 项登录 DOM 测试仍假定没有自动初始化且退出为同步；1 项 HTTP 测试仍假定断线销毁认证。已调整夹具、异步清理及断言，保留相应覆盖，修复后相关 28 项通过。首轮日志及修复后日志分别保存为 room-tests-first.log、targeted-repair.log。

真实浏览器初测发现在线管理列表重复渲染，已移除重复节点。单独复核补充了在途登录/退出顺序、失败握手立即释放占位、过期连接不再接收广播及“降级满员注销”独立终止码；对应自动或浏览器检查通过。新增广播测试曾遗漏合法命令要求的 epoch，修正输入后通过，未把协议错误作为权限拒绝证据。原生自动播放专项增加初始化等待及短音频重新计时后，仍未复现拦截；保留失败结果，不修改范围外的音乐实现。

复核另对照基线检查：仅修改会话、认证入口、配置、共享协议和必要 UI；Core 源码、房间 schema、地图/棋子业务实现和原有历史记录不变。依赖版本不变；新增 dms 配置；管理 target 不是认证 Token；没有把密码、Cookie、Token 或私人内容写入新日志/持久化。复核由本次执行者在单独阶段完成，未进行另一名审计者的独立审计。

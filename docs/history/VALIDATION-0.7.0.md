# SMALLTABLE 0.7.0 实际验证记录

日期：2026-10-22。唯一源码基线：指定的 0.6.9 完整 ZIP，哈希见根 BASELINE.json。未混合历史源码、未推送 GitHub、未操作用户本地部署。

## 已实现

1. 独立恢复页及阶段提示，共用原登录视觉和动画清理；初始会话检查前不先展示登录表单。无会话或终止失效回登录，满员/重连失败可重试，已有桌面临时断线仍保留公开现场并撤除 DM 内容。
2. 可选公共投骰理由：独立 reason 字段，32 Unicode 码点上限，首尾空白不计，拒绝换行及控制字符，按普通文本显示；沿用原随机计算、255 条上限与限流。schema 仍为 3，可读取无理由记录与备份。
3. 登录/恢复页共用 package.json 版本来源，交付版本为 0.7.0。
4. 根目录通用 START-SMALLTABLE.cmd，移除上传脚本的个人穿透域名与 Cpolar 专用提示，不写密码或令牌。启动及检查逻辑保留。本次有实际修改，独立交付。
5. 完整源码包、直接覆盖的增量补丁，均包含对应的前端构建产物。无依赖新增或升级；Core 源码和规则未修改。

## 测试过程中的失败与纠正

- 初次新浏览器用例连续点击触发现有限流，快捷骰未产生预期记录；为测试加入限流间隔，未改动服务端限流。
- 第二次在另一端收到快照后立即读取发起端记录数，遇到发起端尚未渲染的竞态；改为等待两端均显示对应记录。修订后 6 组全部通过。两次失败日志保留于本次证据目录。
- Playwright 常规 Chromium 下载返回损坏内容；改用独立临时 Chromium 二进制。它不属于项目新增依赖，未加入锁文件或交付包。
